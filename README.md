# 🎯 Python Number Guessing Game

A fun and interactive Number Guessing Game developed using Python. The computer randomly selects a number between 1 and 100, and the player has to guess the correct number.

✨ Features
- Random number generation
- User input for guessing
- Hints for higher or lower guesses
- Counts the total number of attempts
- Displays a winning message

🛠️ Technologies Used
- Python 3
- VS Code
- Random Module

📚 Concepts Learned
- While Loops
- If-Else Statements
- Random Module
- User Input
- Break Statement
- Counter Variables
