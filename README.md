# student grade calculator
A beginner friendly python project that calculates a student total marks , percentage and grade based on the marks entered.

FEATURES:
Takes student name as input
Accepts marks in 5 subjects
Calculates total marks
Calculates percentage
Display grade based on percentage
Shows pass or fail status

TECHNOLOGIES USED:
Python 3
